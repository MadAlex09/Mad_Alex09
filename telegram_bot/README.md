# Game Club Booking Bot — EN/RU

Двуязычный Telegram-бот бронирования игровых компьютеров.

## Что добавлено

- английский язык по умолчанию и первым в выборе;
- выбор языка при первом `/start`;
- русский и английский интерфейс;
- сохранение языка пользователя в базе (`user_languages`);
- смена языка через `/language` и раздел Settings/Настройки;
- переведены регистрация, главное меню, профиль, прайс и весь процесс бронирования;
- уведомления администратора оставлены на русском;
- работает с SQLite и PostgreSQL/Neon;
- старые пользователи и брони сохраняются: новая таблица создаётся автоматически.

## Установка

1. Замените файлы проекта файлами из архива.
2. Не удаляйте действующую базу данных и переменные Render.
3. Установите зависимости: `pip install -r requirements.txt`.
4. Локально: `python main.py`.
5. На Render выполните обычный redeploy.

При первом запуске после обновления существующим пользователям один раз покажется выбор языка.
