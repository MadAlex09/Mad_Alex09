# Game Club Booking Bot

Telegram-бот для регистрации клиентов и бронирования игровых компьютеров.

## Возможности

- регистрация по имени и телефону;
- общий зал на 20 компьютеров и VIP-зал на 5 мест;
- выбор длительности, даты и времени;
- защита от пересекающихся броней;
- уведомление администратора;
- профиль клиента со списком броней;
- админ-панель для просмотра и удаления броней;
- хранение данных в PostgreSQL;
- бесплатный запуск через защищённый Telegram Webhook на Render.

## Локальный запуск

1. Создайте `.env` по примеру `.env.example` и задайте переменные окружения.
2. Установите зависимости из корневого `requirements.txt`.
3. Для polling-запуска выполните `python main.py`.

В production бот обрабатывает обновления через `/telegram/webhook`. Для этого
задаются `DATABASE_URL` и `TELEGRAM_WEBHOOK_SECRET`.

Токен Telegram-бота нельзя сохранять в Git или публиковать в коде.
